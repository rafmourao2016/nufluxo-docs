2. Description of Service

NuFluxo is a content automation platform for fitness professionals and personal trainers. It enables creators to schedule and publish educational fitness content to social media platforms including TikTok through authorized API integrations.

3. TikTok API Usage and Data

NuFluxo uses the TikTok Content Posting API to publish content on behalf of authorized users. The following scopes are requested:

user.info.basic — Used to identify the authenticated TikTok account and display basic profile information within the platform.

video.publish — Used to publish video and photo content directly to the user's TikTok profile as authorized posts.

video.upload — Used to upload media files to TikTok's servers as part of the content publishing workflow.
